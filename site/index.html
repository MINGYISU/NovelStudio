    Data safety comes first

    Four layers between you and a lost chapter

    Pick a mishap and see which layer catches it.

    1. 1

      Autosave

      About a second after you stop typing, and at once when you switch sections or leave the page.

    2. 2

      Snapshots

      Earlier versions of every section, taken while you edit and before any replace or restore.

    3. 3

      Hourly database backups

      A full consistent copy on every start and hourly after changes. The newest 20 are kept.

    4. 4

      Cold backup

      One readable JSON file per book, with a SHA-256 checksum, in a folder you choose — ideally on another disk.

    Read a backup without the app 
    # verify the checksum
shasum -a 256 -c my-novel.novelstudio.json.sha256

# print the whole manuscript, in reading order
jq -r '.manuscript[] | recurse(.children[]) | "\n\n## " + .displayTitle + "\n\n" + .plainText' \
  my-novel.novelstudio.json > manuscript.txt

    Get started

    Run it on your own computer

    NovelStudio is a small Node server plus a browser UI that live on your machine. This page is only a tour — there’s no hosted copy of the app, and that’s the point.

    1. 1

      Install Node.js 24 or newer

      The version is pinned in .nvmrc.

    2. 2

      Get the code and build it

      git clone https://github.com/MINGYISU/NovelStudio.git
cd NovelStudio
npm install
npm run build
    3. 3

      Start writing

      npm start   # http://127.0.0.1:4317

      On a Mac you can instead double-click NovelStudio.command. Your books live in ~/Library/Application Support/NovelStudio/.
